# Informasi Ulos Batak

Website informasi dan katalog ulos Batak yang dikembangkan menggunakan PHP dan MySQL.

## Tentang Proyek

Informasi Ulos merupakan proyek website untuk memperkenalkan ulos Batak, budaya Batak, serta informasi produk ulos melalui platform berbasis web.

## Fitur

- Informasi mengenai ulos Batak
- Katalog dan informasi produk
- Halaman administrasi
- Tampilan website berbasis PHP, HTML, CSS, dan JavaScript

## Teknologi

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Menjalankan Proyek

1. Instal XAMPP.
2. Letakkan folder proyek di direktori `htdocs`.
3. Siapkan database MySQL sesuai kebutuhan aplikasi.
4. Sesuaikan konfigurasi koneksi database.
5. Jalankan Apache dan MySQL melalui XAMPP.
6. Buka website melalui `http://localhost/Informasi-Ulos/Informasi-Ulos/` jika folder proyek berada pada jalur tersebut.

## Catatan

Proyek ini dibuat sebagai proyek pembelajaran pengembangan website. Jangan publikasikan kata sandi, kredensial database, atau data pribadi.
